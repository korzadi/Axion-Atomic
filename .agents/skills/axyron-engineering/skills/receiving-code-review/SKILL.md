# Recepción de revisión

1. Lee todo el comentario y localiza el código afectado.
2. Reformula el problema técnico y el resultado que propone.
3. Verifica la afirmación contra implementación, contratos, tests y requisitos.
4. Distingue comentario correcto, parcialmente correcto, incorrecto o ambiguo.
5. Si es correcto, implementa un cambio pequeño y prueba la regresión.
6. Si es incorrecto, responde con evidencia técnica respetuosa y concreta.
7. Si falta información que cambia el comportamiento esperado, pregunta antes de implementar.
Nunca aceptes o rechaces comentarios por deferencia; no cambies código a ciegas ni ocultes desacuerdos técnicos.
