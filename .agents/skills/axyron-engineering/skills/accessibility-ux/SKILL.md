# Accesibilidad y experiencia de usuario

- Usa HTML semántico y controles nativos cuando sea posible.
- Asegura navegación completa por teclado, orden de foco lógico y foco visible.
- Etiqueta inputs, botones, regiones y errores; no dependas solo del color o iconos.
- Respeta contraste, zoom, reducción de movimiento y tamaños táctiles.
- Usa roles ARIA solo cuando la semántica nativa no sea suficiente.
- Gestiona diálogos, menús, alertas y cambios dinámicos de foco.
- Proporciona estados de carga, éxito, vacío y error comprensibles.
- Prueba responsive y accesibilidad con herramientas disponibles; informa lo que no pudo probarse.
